TF.NX @VERSION@ - TF.EX for TowerFall on Nintendo Switch
===========================================================

TF.NX carries TF.EX @TFEX@ (online play with rollback, crossplay with the PC and the browser) and the
Switch port of FortRise's mod loading. It contains no game files: you need your own TowerFall
(Switch, version 1.4.1.6) and a Switch running Atmosphere.

INSTALL
  1. Extract this zip onto the root of your SD card (it adds atmosphere/ and xplay/).
  2. Start TowerFall. NETPLAY is on the main menu; mods are on the MODS screen.

MODS
  Mods go in sd:/xplay/mods/<mod>/, each the mod's PC release folder unchanged.
  - Archer, skin and tower mods (content only): drop them in, as on the PC.
  - Code mods work when TF.NX carries their logic (the list: MODS.txt). Included here:
@INCLUDED@
  - WiderSet (8 players, wide lobbies): download WiderSet 0.9.0 from GameBanana and put its folder
    in sd:/xplay/mods/.

UPDATING
  TF.EX's servers only let its latest version play online: install each new TF.NX release the
  same way (extract over the old one).
